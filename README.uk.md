# UNYRI

**UNYRI** — месенджер із наскрізним шифруванням для iPhone та Android і сервер, який можна розгорнути в себе. Повідомлення, файли й дзвінки шифруються на телефонах (протокол Signal, бібліотека libsignal); сервер зберігає й пересилає лише зашифровані дані, облікові записи та службові відомості про доставку.

## Навіщо UNYRI

Свої люди. Свій сервер. Свої правила. UNYRI залишає зв’язок у ваших руках: поставте сервер удома, у друга чи на орендованому комп’ютері в будь-якій країні й спілкуйтеся через нього з близькими. Немає однієї компанії, яка вирішує, хто з ким може говорити, і може вимкнути зв’язок одразу всім: залишайтеся на зв’язку, не залежачи від великих платформ.

## Долучайтеся до розробки

UNYRI — відкритий проєкт, і допомогти може кожен: кодом (iPhone, Android, сервер), перекладами, тестами на своїх телефонах, дизайном, інструкціями для тих, хто ставить свій сервер, або просто ідеями й повідомленнями про помилки.

- Знайшли помилку чи маєте ідею — створіть [issue](https://github.com/nndimka-ops/UNYRI/issues) українською, російською чи англійською.
- Хочете надіслати код — прочитайте [CONTRIBUTING.md](CONTRIBUTING.md): там коротко, як оформити pull request, і про умови ліцензії для внесків.
- Знайшли вразливість — не пишіть у відкриті issues, скористайтеся закритим повідомленням (вкладка **Security**).

## Що вміє

- Особисті чати з наскрізним шифруванням, позначки доставки й прочитання, відповіді, пересилання, реакції, «Збережене».
- Фото, відео, файли, голосові повідомлення та відеокружечки; великі файли можна передати напряму з телефона на телефон.
- Аудіо- та відеодзвінки, групові кімнати.
- Постійний публічний номер і необов'язкове @ім'я, QR-код профілю, контакти й налаштування приватності.
- Кілька облікових записів в одному застосунку, зокрема на різних серверах.
- Резервна копія та перенесення історії на новий телефон, ключ відновлення, блокування застосунку.
- Власний сервер: інсталятор для Windows і Linux (Docker) та панель власника в застосунку.

## Що де лежить

| Тека | Що це |
| --- | --- |
| `server/` | Сервер на Rust, його адмін-консоль, міграції бази даних і тести |
| `ios/` | Застосунок для iPhone (Swift/SwiftUI), розширення «Поділитися» та служба сповіщень |
| `android/` | Застосунок для Android (Kotlin, Jetpack Compose) |
| `shared/` | Спільні тестові дані застосунків і сервера |
| `scripts/selfhost/`, `docker-compose.selfhost.yml` | Інсталятор і конфігурація власного сервера |
| `docs/` | Інструкція з власного сервера |

## Де взяти застосунки

- **Android:** підписані APK додано до релізів `android-vX.Y.Z` на цій сторінці.
- **iPhone:** через Apple (App Store / TestFlight). Тут лише вихідний код, файли IPA не публікуються.
- **Сервер:** до кожного релізу `server-vX.Y.Z` додаються готові образи (`ghcr.io/nndimka-ops/unyri-server`, `unyri-minio`, `unyri-mc`) та архіви з контрольними сумами: потрібен лише Docker, компілятор не потрібен.

## Збирання з вихідного коду

- **Сервер:** `cargo build --release --manifest-path server/Cargo.toml`; тести: [server/tests/README.md](server/tests/README.md); образ: `docker build -f server/Dockerfile .`; перевірка релізних архівів: `python3 scripts/check_selfhost_release.py`.
- **Android:** JDK 17 та Android SDK, потім `cd android && ./gradlew assembleDebug` (докладніше: [android/README.md](android/README.md)). Для push-сповіщень потрібен власний проєкт Firebase: покладіть його `google-services.json` в `android/app/`; без нього застосунок збирається й працює, лише без push.
- **iPhone:** Mac з Xcode 26.5; відкрийте `ios/UNYRI.xcodeproj` (залежності та завантаження бібліотеки Signal: [ios/README.md](ios/README.md)). Для запуску на телефоні потрібен підпис власною командою Apple.

## Хобі-проєкт

UNYRI — невеликий некомерційний хобі-проєкт, який розвивається у вільний час. Він безкоштовний і без реклами. Застосунки й сервер надаються «як є», без будь-яких гарантій: можливі помилки, збої та втрата даних. Використовуйте UNYRI на власний ризик, зберігайте важливе окремо й не покладайтеся на нього для екстреного зв’язку чи там, де збій може завдати шкоди.

# UNYRI

**UNYRI** — мессенджер со сквозным шифрованием для iPhone и Android и сервер, который можно поднять у себя. Сообщения, файлы и звонки шифруются на телефонах (протокол Signal, библиотека libsignal); сервер хранит и пересылает только зашифрованные данные, аккаунты и служебные сведения о доставке.

## Зачем UNYRI

Свои люди. Свой сервер. Свои правила. UNYRI оставляет связь в ваших руках: поставьте сервер дома, у друга или на арендованном компьютере в любой стране и общайтесь через него с близкими. Нет одной компании, которая решает, кто с кем может говорить, и может отключить связь сразу всем: оставайтесь на связи, не завися от больших платформ.

## Что умеет

- Личные чаты со сквозным шифрованием, отметки доставки и прочтения, ответы, пересылка, реакции, «Избранное».
- Фото, видео, файлы, голосовые сообщения и видеокружки; большие файлы можно передать напрямую с телефона на телефон.
- Аудио- и видеозвонки, групповые комнаты.
- Постоянный публичный номер и необязательное @имя, QR-код профиля, контакты и настройки приватности.
- Несколько аккаунтов в одном приложении, в том числе на разных серверах.
- Резервная копия и перенос истории на новый телефон, ключ восстановления, блокировка приложения.
- Свой сервер: установщик для Windows и Linux (Docker) и панель владельца в приложении.

## Что где лежит

| Папка | Что это |
| --- | --- |
| `server/` | Сервер на Rust, его админ-консоль, миграции базы и тесты |
| `ios/` | Приложение для iPhone (Swift/SwiftUI), расширение «Поделиться» и служба уведомлений |
| `android/` | Приложение для Android (Kotlin, Jetpack Compose) |
| `shared/` | Общие тестовые данные приложений и сервера |
| `scripts/selfhost/`, `docker-compose.selfhost.yml` | Установщик и конфигурация своего сервера |
| `docs/` | Инструкция по своему серверу |

## Где взять приложения

- **Android:** подписанные APK прикреплены к релизам `android-vX.Y.Z` на этой странице.
- **iPhone:** через Apple (App Store / TestFlight). Здесь только исходный код, файлы IPA не публикуются.
- **Сервер:** к каждому релизу `server-vX.Y.Z` прилагаются готовые образы (`ghcr.io/nndimka-ops/unyri-server`, `unyri-minio`, `unyri-mc`) и архивы с контрольными суммами: нужен только Docker, компилятор не нужен.

## Сборка из исходников

- **Сервер:** `cargo build --release --manifest-path server/Cargo.toml`; тесты: [server/tests/README.md](server/tests/README.md); образ: `docker build -f server/Dockerfile .`; проверка релизных архивов: `python3 scripts/check_selfhost_release.py`.
- **Android:** JDK 17 и Android SDK, затем `cd android && ./gradlew assembleDebug` (подробнее: [android/README.md](android/README.md)). Для push-уведомлений нужен свой проект Firebase: положите его `google-services.json` в `android/app/`; без него приложение собирается и работает, только без push.
- **iPhone:** Mac с Xcode 26.5; откройте `ios/UNYRI.xcodeproj` (зависимости и загрузка библиотеки Signal: [ios/README.md](ios/README.md)). Для запуска на телефоне нужна подпись своей командой Apple.

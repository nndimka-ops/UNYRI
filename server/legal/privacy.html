Конфиденциальность UNYRI

Кто отвечает за данные

Этот сервер работает на открытом коде UNYRI. Им управляет его оператор — тот, кто установил сервер, а не разработчики UNYRI. Имя и контакт оператора показаны в приложении на карточке сервера.

Что видит сервер

Содержимое личных сообщений, файлов и звонков защищено сквозным шифрованием, и сервер не может его прочитать. Сервер получает данные аккаунта, метаданные подключений и доставки, а также отчёты, которые вы отправляете сами.

Хранение и удаление

Сроки хранения, резервные копии и правила этого сервера определяет его оператор. Удалить аккаунт можно в приложении; по остальным вопросам обращайтесь к оператору.

UNYRI Privacy

Who is responsible

This server runs the open-source UNYRI server. It is operated by whoever installed it, not by the UNYRI developers. The operator name and contact are shown in the app on the server card.

What the server sees

Private message, file and call content is end-to-end encrypted, and the server cannot read it. The server receives account data, connection and delivery metadata, and reports you choose to send.

Retention and deletion

Retention, backups and the rules of this server are set by its operator. You can delete your account in the app; ask the operator about anything else.

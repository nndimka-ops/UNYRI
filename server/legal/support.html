Поддержка

Вопросы по этому серверу

Аккаунты, доступ и правила этого сервера — к его оператору: контакт показан в приложении на карточке сервера. Не отправляйте пароли и ключи восстановления.

Ошибки в программе

Об ошибках в серверной программе UNYRI сообщайте через раздел issues репозитория проекта. Встроенный отчёт приложения отправляется оператору выбранного сервера.

Support

About this server

Accounts, access and the rules of this server: ask its operator; the contact is shown in the app on the server card. Never send passwords or recovery keys.

Software problems

Report problems in the UNYRI server software through the project repository issues. The app's built-in report goes to the operator of the selected server.
